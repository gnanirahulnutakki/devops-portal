# Backstage-Era Archive

These documents are historical.

They describe earlier phases of the repository when the portal was modeled as a Backstage app with custom plugins, separate package roots, and different CI and deployment assumptions.

## What This Archive Is For

- repo archaeology
- understanding older design decisions
- tracing previous implementation plans
- recovering historical operational context when needed

## What This Archive Is Not For

- onboarding to the current runtime
- production deployment guidance for the active portal
- authoritative API or architecture references
