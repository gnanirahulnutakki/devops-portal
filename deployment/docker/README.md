# Legacy Docker Path

This directory is preserved from the older Backstage-era implementation.

It is not the supported container or compose path for the active `devops-portal` runtime.

Use these paths instead:

- root `Dockerfile`
- root `docker-compose.yml`
- `helm/devops-portal/`

Read these first before using any deployment asset in this repository:

- `docs/architecture/CURRENT_RUNTIME_ARCHITECTURE.md`
- `docs/development/CURRENT_RUNTIME_MAINTAINER_HANDOFF.md`
- `docs/legacy/SOURCE_TREE_STATUS.md`

If this directory is still needed by an external workflow, that dependency should be documented explicitly before any future deletion.
